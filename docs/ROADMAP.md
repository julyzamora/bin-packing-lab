# Roadmap

1. Add established 1D/vector benchmark collections with provenance and exact small-instance baselines.
2. Add rearrangement track: validated starting assignment, stable bin IDs, movement cap.
3. Add bin evacuation, swap chains, beam search, and adaptive large-neighborhood candidates.
4. Add isolated candidate execution and frozen independent evaluation service.
5. Add provider-neutral coding-agent adapter and restart-safe experiment queue with per-direction claims.
6. Add hidden test campaigns and independent review/promotion workflow.
7. Deploy leaderboard website and authenticated submissions. Keep research operations and scoring separate.

The repo starts with a functioning development benchmark and leaderboard, not claims that
the advanced algorithms or autonomous controller above already exist.
